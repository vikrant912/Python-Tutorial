Conditional branching 
1. The if and else Statements
This is the simplest form of branching, used when you have two possible paths (a "Yes/No" scenario).

if: Checks if a condition is met.

else: Provides a "fallback" plan if the if condition is not met.

Syntax Example:

Python
if variable == condition:
    # This code runs if the condition is True
else:
    # This code runs if the condition is False
2. The elif Statement
Short for "else if," elif is used when you have more than two possible outcomes. You can use as many elif blocks as you need between the if and the else.

if: The first check.

elif: Subsequent checks if the previous ones failed.

else: The final catch-all if none of the conditions were met.

3. Practical Example
Think of it like checking the temperature to decide what to wear:

Python
temp = 25

if temp > 30:
    print("It's hot! Wear a T-shirt.")
elif temp > 15:
    print("It's pleasant. A light jacket is fine.")
else:
    print("It's cold! Wear a heavy coat.")


****Important Note: In Python, indentation (the space at the beginning of the line) is strictly required.
 It tells Python which lines of code belong to which branch.

STDIN and STDOUT:
STDIN - Standard Input

STDOUT - Standard Output

A Quick Breakdown
1. Conditional Operators
These are used to compare two values. They always result in either True or False.

Example: 5 > 3 is True, while 5 == 3 is False.

Common Pitfall: Use == (double equals) for comparison. Using a single = is for assigning a value to a variable.
####################################################################
2. STDIN & STDOUT
These are the basic ways a program communicates with the outside world:

STDIN (Standard Input): How the program gets information. In Python, this is usually the input() function where a user types something.

STDOUT (Standard Output): How the program shows information. In Python, this is usually the print() function that displays text on your screen.

Looping with For
We could use a for loop to perform geoprocessing tasks on each layer in a list.

We could get a list of features in a feature class and loop over each, checking attributes.

Anything in a sequence or list can be used in a for loop.

Just be sure not to modify the list while looping.
